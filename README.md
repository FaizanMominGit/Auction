# Auction Portal Project

This repository contains the codebase for an online auction portal, built primarily in Java with some Python components.

> **Note:** The server for this project is currently not running. As a result, features like auction scheduling and automatic auction closing will not work until you set up and start the server.

## Features

- User registration and authentication
- Create and manage auction listings
- Place bids on auctions
- View bidding history and results

## Tech Stack

- **Java**
- **Python**
