# Auction Portal Project

This repository contains the codebase for an online auction portal, built primarily in Java with some Python components.

## Brief Description

Our Auction Portal app is a platform that enables users to create, manage, and participate in online auctions. Users can register, list items for auction, place bids in real-time, and track their bidding history. The app is designed to provide a simple and efficient way to conduct auctions digitally, ensuring transparency and ease of use for both buyers and sellers. It is mainly built using Java, with some supporting components in Python.

> **Note:** The server for this project is currently not running. As a result, features like auction scheduling and automatic auction closing will not work until you set up and start the server.

## Features

- User registration and authentication
- Create and manage auction listings
- Place bids on auctions
- View bidding history and results
